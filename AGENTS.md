# Repository operating rules

- Audit first and identify the owning file before editing.
- This is the artistic website; the professional hub remains in `../artan-live`.
- Preserve HTML, JSON, CSS, JS, and configuration as separate owners.
- Preserve app entry -> domain importer -> section module separation.
- Keep page HTML as a mount shell; load structures from fragments and content from JSON.
- Follow the approved artan-live / Neuroartan / Control Center design baseline.
- Audit the token bridge before styling; do not invent parallel token values.
- Do not copy existing source defects or unrelated CV content.
- Do not use absolute local sibling paths as browser runtime dependencies.
- Every created runtime module must be wired and verified.
- No duplicated assets, frontend secrets, hacks, or compensating style layers.
- Do not change other repositories, publish, or configure domains without scope authorization.
- Report scaffolded and unverified behavior honestly.
